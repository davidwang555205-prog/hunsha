# Bridal & Dress Content Studio

婚纱、礼服和裙装品牌内容生成 Demo。

## 功能

- 选择婚纱 / 礼服或裙装 / 女装品类
- 选择款式、图片类型、场景、模特、季节和光线
- 本地预览参考图，不上传服务器
- 生成英文图片 Prompt
- 生成中文小红书内容 Demo
- 为每张配图生成独立英文 Prompt
- 一键复制最终 Prompt、全文或单张配图 Prompt

## Demo 范围

- 不做账号登录
- 不接入真实生图 API
- 不需要后端服务
- 上传参考图仅用于浏览器本地预览

## 本地运行

```bash
npm install
npm run dev
```

## 构建检查

```bash
npm run typecheck
npm run build
```
